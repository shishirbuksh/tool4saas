# Tool4SaaS — Astro Framework Guidelines

This project uses the latest Astro framework with static site generation (SSG) and React components for interactive tools. Next.js has been completely removed.

- Framework: Astro (SSG)
- Configuration: `astro.config.mjs`
- MCP / Tooling: `opencode.json` configured with Astro docs remote MCP server
- Pages: `src/pages/`
- React Views: `src/views/`
- Layouts: `src/layouts/`
- Scripts & Validation: `scripts/`
